# MoyaPanel update channel

Public signed update packages for MoyaPanel Desktop.

- Manifest: `updates/stable.json`
- Archives: `updates/releases/`
- Clients verify the pinned publisher Ed25519 public key and payload hashes.
- No client GitHub token is required.
- User accounts, passwords and publisher private keys are not published here.

Publisher tooling and signing key are kept separately by the owner.
