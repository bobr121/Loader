# MoyaPanel signed update channel

Initial installer: [MoyaPanel Setup 1.3.0](downloads/MoyaPanel-Setup-1.3.0.zip)

- Public signed manifest: updates/stable.json
- Update archives: updates/releases/
- Clients verify Ed25519 signatures and SHA-256 hashes.
- Clients need no GitHub token; checks are staggered and updates apply on next launch.
- Accounts, passwords and publisher private keys are not stored in this repository.
- Publisher tooling/signing key are kept separately by the owner.

Initial installation of the updater is required once. Windows and 1000-client load testing are not claimed.
